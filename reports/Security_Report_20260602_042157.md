- 3. 생성된 최종 절대 경로가 1단계에서 지정한 안전한 기본 디렉터리 내에 포함되어 있는지 `startsWith()` 메서드로 검증합니다. 이 검사를 통해 `../`와 같은 경로 조작 문자를 사용한 상위 디렉터리 접근 시도를 원천적으로 차단합니다.

- 4. 경로 검증을 통과한 경우에만 `res.sendFile()`을 호출하여 파일을 전송하고, 실패 시 403 Forbidden 에러를 반환하여 요청을 거부합니다.
